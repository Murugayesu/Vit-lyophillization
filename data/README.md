# Data Directory

## Proxy Dataset: MVTec AD — "Bottle" Category

**Source:** https://www.mvtec.com/company/research/datasets/mvtec-ad
**Used as:** Pharma vial defect proxy (bottle → vial analogy)
**Classes mapped:**
- `good` → defect-free vial
- `broken_large` → collapse / severe structural defect
- `broken_small` → meltback / partial structural defect
- `contamination` → skinning / surface contamination

## Collection Protocol
- Images are publicly available industrial defect images
- Used solely as a proxy to demonstrate the pipeline
- Camera: MVTec standardized setup (documented in original paper)
- Resolution: 900×900 px, resized to 224×224 for training

## Metadata
- See `metadata.csv` (generated by `src/dataset.py`) after running `prepare_data.py`
- Splits are vial-level (bottle-id level), frozen with seed 42

## Note for Reviewers
Real lyophilized vial images are proprietary; this proxy dataset is used to demonstrate pipeline feasibility. The framework is architecture-agnostic and can be re-trained on real vial images with the same code.
